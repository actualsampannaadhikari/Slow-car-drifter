# Slow Drifter

A calm, endless drive in the browser, inspired by slow-paced road games. Procedural hills, curves, forests, villages, snow and desert, with a living sky. Music and every sound are generated live with the Web Audio API. No build step, no dependencies.

## Play

Open `index.html`, or serve the folder:

```
python3 -m http.server 8000
```

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Steer | A D or arrow keys | Hold left or right side |
| Speed | W S or up and down | Faster and Slower buttons |
| Nitro boost | Hold Shift | Boost button |
| Autopilot | Space | Menu |
| Weather | R | Menu |
| Time of day | T | Menu |
| Camera | C | Menu |
| Next owned car | V | Menu |
| Garage | G | Menu |
| Sound | M | Menu |
| Hide display | H | |
| Menu | P or Escape | Menu button |

## Features

- Endless road with rolling hills and curves
- Four biomes that blend into each other: meadows, autumn woods, frozen pines, red desert
- Villages with lit houses and street lamps
- Full day and night cycle with sun, moon, stars, aurora and shooting stars
- Clear, rain, thunderstorm with lightning and thunder, snow and fog
- A rainbow after the rain, birds, a hot air balloon, fireflies, falling leaves and petals
- Nitro boost with a wider field of view and speed lines
- Two-way traffic: overtake and near-miss for cash, crashes cost speed and nitro
- Levels with distance goals and a cash payout for each one
- Garage with six cars to buy, each with its own speed, grip and nitro
- Gold orbs to collect on the road
- Progress, money and cars saved in local storage
- Five cameras: chase, high, hood, bumper and drone
- Generative ambient music, plus birdsong, crickets, thunder and engine sound
- Autopilot for pure scenery watching

## Deploy

Enable GitHub Pages on the repository root. Any static host works.
